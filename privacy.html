プライバシーポリシー

Soremaji YouTube Uploader は YouTube API Services を利用します。運営者が Google OAuth で許可したチャンネルのみを対象にします。

取得・利用するデータ

アップロード権限で動画、タイトル、説明、タグ、公開設定と予約時刻を YouTube に送信します。読み取り権限でチャンネル ID、動画 ID、公開・処理状況を照合し、二重投稿を防ぎます。テーマ調査には公開動画のタイトル、再生数などの公開情報を使用します。

保存と共有

認証トークンは運営者の Mac のアクセス制限付きファイルに保存します。投稿記録、URL、チャンネル情報、検査結果もローカルに保存し、予約の確認や障害対応に使います。Google 認証情報はこの公開サイトに保存しません。認証と投稿のため Google・YouTube と通信します。取得データを広告目的で販売することはありません。

アクセスの取消しと削除

Google アカウントの接続管理からアクセスを取り消せます。ローカルの記録・トークンの削除については運営者にご連絡ください。投稿済みの動画は YouTube Studio で別途管理できます。

このサイトについて

この案内サイトは GitHub Pages 上にあります。アクセス時に GitHub がセキュリティのため IP アドレスを記録します。サイト独自の広告・アクセス解析は使用しません。
